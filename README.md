# Sagittarius

本地记账 / 饮食记录 + AI 管家的 Android 应用。

## 功能

- **记账与预算**：收支记录、分类、预算树、统计、CSV 导出
- **饮食与营养**：饮食记录、本地中国食物营养库、营养目标
- **AI 管家**：多服务商，对话式记账、查询、预算分配，支持工具权限控制
- **界面**：透明桌宠、深色 / 浅色主题、天气与悬浮窗

## 安装

1. 打开 [Releases](https://github.com/AsaMitaka2007/Sagittarius/releases/latest)
2. 下载 `sgr-release-1.0.apk`
3. 在手机上允许安装未知来源应用后安装
4. 系统要求：Android 8.0（API 26）及以上

首次打开后，在设置中填写自己的 API Key 即可使用。
